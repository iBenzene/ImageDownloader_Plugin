# AI Agent Guidelines

## Comment Rules

- Start source files with a path header comment (e.g. `// src/foo.ts`).
- Write comments in Chinese using half-width commas (`, `), corner quotes (`「」`/`『』`), and no trailing punctuation. Do not use semicolons; avoid colons.
- Keep comments meaningful and intent-focused; avoid mechanical or AI-sounding restatements of the code.
